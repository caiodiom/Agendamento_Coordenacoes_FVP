📅 Agendamento de Coordenações – FVP

Agendamento_Coordenacoes_FVP é um sistema web desenvolvido para gerenciar o agendamento de atendimentos das coordenações de uma faculdade, oferecendo uma experiência simples, organizada e eficiente tanto para alunos quanto para a equipe administrativa.

🧾 Sobre o Projeto

O sistema permite que usuários realizem agendamentos de atendimento com as coordenações acadêmicas, centralizando horários, evitando conflitos e otimizando o fluxo de atendimentos institucionais.

O projeto foi desenvolvido com foco em:

Usabilidade

Organização dos atendimentos

Facilidade de manutenção

Interface moderna e responsiva

🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

Vite – Build tool rápida e moderna

TypeScript – Tipagem estática para maior confiabilidade

React – Biblioteca para construção da interface

shadcn/ui – Componentes reutilizáveis e acessíveis

Tailwind CSS – Estilização utilitária e responsiva
